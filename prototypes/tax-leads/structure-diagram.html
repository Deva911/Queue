One message, start to finish

  1. The client types "Hi", or picks "Personal tax return", in WhatsApp.
  2. Meta forwards that message to your bot server's front door. Meta sometimes sends the same message twice, so the front door skips any it has already handled.
  3. The bot looks up this client's conversation in Supabase to see which question they are on. Keeping this in the database means a server restart loses nothing.
  4. The question logic (the part you already built) checks the answer. A bad email keeps them on the same question with a short explanation. A good answer moves them to the next question.
  5. The bot saves the answer and the new position. After the last question it saves a complete lead.
  6. The reply sender sends the next question, or the thank-you and document checklist, back through Meta to the client's WhatsApp.
  7. The dashboard reads the leads from Supabase.
  8. The consultant logs in, sees who wants a call back, and marks each lead as contacted.

Build order

  1. Step 1Change lead_store.py to save to Supabase instead of the file.
  2. Step 2Add the bot server (front door and reply sender) and test it with Meta's free test number.
  3. Step 3Point the dashboard at Supabase and add a login.
  4. Step 4Put it online and try it with a few friendly clients.

Each step works on its own before the next one starts. Secret keys for Meta and Supabase live in settings on the server, never in the code.
